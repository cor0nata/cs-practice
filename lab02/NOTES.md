Git  это программа на моем компьютере. GitHub это сайт в интернете, куда я выкладываю репозитории
git diff сравнивает папку и индексс
git diff -- staged сравнивает индекс и последний коммит
git status показывает текущее состояние каталога и индекса
Ветка указатель на один из коммитов.При новом коммите указатель с текущей ветки смещается на новый коммит.Слияние это процесс объединения изменений из одной ветки в другую
